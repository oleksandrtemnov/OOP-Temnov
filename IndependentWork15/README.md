Самостійна робота №15: Власна реалізація Retry з Exponential Backoff

## Опис реалізації
Розроблено узагальнений клас `RetryPolicy`, який підтримує:
- налаштування максимальної кількості повторів (`_maxRetries`), початкової затримки (`_initialDelay`) та коефіцієнта розкиду (`_jitterFactor`);
- фільтрацію винятків через делегат `Func<Exception, bool>? shouldRetry`;
- розрахунок затримки за формулою експоненційного backoff із випадковим jitter та логування кожної спроби.
