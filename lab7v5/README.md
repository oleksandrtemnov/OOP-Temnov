Звіт з лабораторної роботи №7
Тема: Приховування методів (new) vs перевизначення (override).
Предмет: Об’єктно-орієнтоване програмування
Студент: Темнов Олександр
Група КН-3/1 Варіант: Варіант №5 (Document → PDF / Text)
Навчальний заклад: Рівненський фаховий коледж інформаційних технологій
1. Мета роботи
Зрозуміти різницю між приховуванням методів за допомогою ключового слова new та перевизначенням через virtual/override, а також навчитися правильно обирати між цими підходами.
2. Опис реалізованих класів
Document — базовий клас із властивістю Title та віртуальним методом virtual void Open().
PDF — похідний клас A, який перевизначає метод Open() за допомогою override.
Text — похідний клас B, який приховує метод Open() базового класу за допомогою new.
