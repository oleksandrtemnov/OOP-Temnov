 Короткий опис реалізованої системи

В рамках роботи реалізовано поліморфну систему доставки товарів (`DeliveryService`), що містить:
Базовий клас: `abstract class DeliveryService` з абстрактними методами `Deliver(string address)` та `Validate(string address)`, а також загальною перевіркою наявності товару.
Похідні класи:
  1. `CourierDelivery` — кур'єрська доставка (валідація наявності назви вулиці/проспекту).
  2. `PostDelivery` — поштова доставка (валідація 5-значного поштового індексу).
  3. `PickupDelivery` — самовивіз (валідація префіксу ID пункту видачі `PICKUP-`).
Сервісний клас:** `OrderDeliveryManager` з методом `DeliverAll()`, який працює зі списком базового типу `DeliveryService`, поліморфно викликає метод доставки та перехоплює кастомні винятки `DeliveryException`.
