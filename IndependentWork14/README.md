Самостійна робота №14: Кейси відмовостійкості з бібліотекою Polly

## Опис реалізації
У проєкті реалізовано та залоговано три практичні сценарії відмовостійкості за допомогою `ResiliencePipelineBuilder` (Polly v8):
1. **Підключення до БД** — політика `Retry` з експоненційною затримкою та jitter.
2. **Відправка повідомлень у чергу** — політика `Circuit Breaker` для захисту від каскадних збоїв.
3. **Генерація звіту** — комбінація `Timeout` та `Fallback` для повернення кешованого результату при перевищенні часу очікування.
