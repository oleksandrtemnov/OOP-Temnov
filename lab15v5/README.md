## 1. Мета роботи
Ознайомитися з принципами роботи технології LINQ (Language Integrated Query) у C#, навчитися формувати запити до об'єктних колекцій за допомогою синтаксису запитів (Query Syntax) та синтаксису методів (Method Syntax), використовувати операції фільтрації (`Where`), з’єднання (`Join`, `GroupJoin`), проєкції (`Select`) та агрегації (`Sum`, `Max`, `OrderByDescending`), а також дослідити швидкодію обох підходів за допомогою класу `Stopwatch`.
## 2. Постановка задачі (Варіант 5)
Спроєктувати модель даних для системи управління замовленнями, що складається з двох сутностей:
1. Клієнт (`Customer`): ідентифікатор (`Id`), ім'я (`Name`), місто (`City`).
2. Замовлення (`Order`): ідентифікатор (`Id`), дата оформлення (`OrderDate`), ідентифікатор клієнта (`CustomerId`), загальна сума (`TotalAmount`).

Сформувати тестові колекції (`List<Customer>` та `List<Order>`) і реалізувати два варіанти (Query Syntax та Method Syntax) для кожного з 4 запитів із вимірюванням часу їх виконання:
1. Отримати всі замовлення, зроблені клієнтами з міста Kyiv, сума яких перевищує 1000 грн.
2. Вивести дату кожного замовлення та ім'я клієнта, який його оформив.
3. Обчислити загальну суму замовлень для кожного клієнта (включно з тими, хто ще не робив замовлень).
4. Знайти замовлення з максимальною сумою.

## 5. Висновки
Під час виконання лабораторної роботи №15 було реалізовано систему обробки даних про клієнтів та їхні замовлення на мові C# із використанням технології LINQ to Objects. 

Було на практиці порівняно два способи запису LINQ-виразів:
* **Query Syntax** (синтаксис запитів) є декларативним, візуально нагадує SQL і зручніший для складних з'єднань (`join ... into`).
* **Method Syntax** (синтаксис методів розширення) є гнучкішим та лаконічнішим при використанні агрегатних функцій і сортування (`OrderByDescending`, `FirstOrDefault`).

Вимірювання часу за допомогою `Stopwatch` показало, що на невеликих колекціях продуктивність обох підходів практично однакова (різниця становить частки мілісекунди і зумовлена переважно JIT-компіляцією під час першого виклику методу). Виняток становить Запит 4, де вкладений пошук `Max()` всередині `where` у Query Syntax має квадратичну складність O(n^2), тоді як сортування або однопрохідний пошук у Method Syntax працює значно ефективніше.
