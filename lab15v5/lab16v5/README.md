1. МЕТА РОБОТИ
Навчитися використовувати оператор SelectMany для роботи з вкладеними колекціями, реалізовувати пагінацію даних за допомогою LINQ (методи Skip та Take), а також створювати власні методи розширення (Custom Extension Methods) для IEnumerable<T>.


2. КОРОТКІ ТЕОРЕТИЧНІ ВІДОМОСТІ ТА ОПИС СУТНОСТЕЙ

У ході виконання варіанту №5 створено 3 доменні сутності з вкладеними колекціями:
1. Landmark (Id, Name) — пам'ятка.
2. City (Id, Name, Population, List<Landmark>) — місто, яке містить вкладений список пам'яток та показник населення.
3. Country (Id, Name, List<City>) — країна, яка містить вкладений список міст.

Реалізовані рішення:
- SelectMany: Дозволяє виконати проекцію та об'єднання (flattening) 3-рівневого дерева (Country -> City -> Landmark) в одну плоску послідовність IEnumerable<Landmark>.
- Пагінація: Використано комбінацію методу Skip((pageNumber - 1) * pageSize) для пропуску елементів та Take(pageSize) для отримання порції даних з 4 міст на сторінку.
- Custom Extension: Створено статичний метод розширення TotalPopulation(this IEnumerable<City> cities), що обчислює сумарну кількість населення для будь-якої послідовності міст через внутрішній виклик Sum().
